# SCIENTIFIC_EVALUATION_PROTOCOL.md

This document defines the rigorous, evidence-based scientific evaluation protocol that AlphaAlgo uses to validate self-improving candidate modifications.

---

## 1. Core Principles of Scientific Evaluation

To ensure that the Evolution Engine is guided by objective statistical power rather than stochastic drift or overfitting, all candidate evaluations must adhere to the following principles:

1. **Controlled Comparison**: Every test must run as a paired champion-challenger trial, feeding identical, deterministic market tick streams under identical seeds.
2. **Multi-Dimensional Metrics**: Candidate performance is graded across a multi-dimensional matrix covering logic, calibration, latency, memory, and trading risk.
3. **Rigorous Statistical Testing**: Observed improvements must pass paired Wilcoxon Signed-Rank and Sign-Tests to guarantee statistical significance.
4. **Adversarial Falsification**: Evaluation actively attempts to break the candidate using volatility shocks, corrupted inputs, and stale memories.

---

## 2. Statistical Sign-Test and Wilcoxon Formulation

Let $X_{P}$ be the distribution of a target metric (such as decision Variational Free Energy or PnL) generated by the active Champion $\mathcal{M}_P$ across $N$ independent evaluation intervals, and $X_{C}$ be the corresponding metric distribution generated by the Challenger candidate $\mathcal{M}_C$.

The paired difference for each interval $i$ is defined as:

$$D_i = X_{C, i} - X_{P, i}$$

### A. The Non-Parametric Sign-Test
The Sign-Test evaluates the direction of differences. Let $W^{+}$ be the number of intervals where $D_i > 0$ and $W^{-}$ be the number of intervals where $D_i < 0$. Under the null hypothesis $H_0$ that the candidate does not improve performance:

$$W^{+} \sim \text{Binomial}\left(N' = W^{+} + W^{-}, p = 0.5\right)$$

The one-tailed $p$-value is calculated as:

$$p = \sum_{k=W^{+}}^{N'} \binom{N'}{k} 0.5^{N'}$$

### B. Wilcoxon Signed-Rank Test
To account for both the sign and the magnitude of the differences, the differences $D_i$ are ranked according to their absolute value $|D_i|$. Let $R_i$ be the rank assigned to $|D_i|$. The Wilcoxon test statistic $W$ is:

$$W = \sum_{D_i > 0} R_i$$

For $N > 20$, the test statistic $W$ converges to a normal distribution:

$$Z = \frac{W - \mu_W}{\sigma_W} \sim \mathcal{N}(0, 1)$$

$$\text{where } \mu_W = \frac{N'(N'+1)}{4}, \quad \sigma_W = \sqrt{\frac{N'(N'+1)(2N'+1)}{24}}$$

A Challenger is promoted only if the paired $Z$-score is significant:

$$p\text{-value}(Z) < 0.01$$

## 3. Data Contamination and Overfitting Safeguards

A critical failure mode of self-improving architectures is **evaluator gaming**—where the candidate optimizes directly against the test dataset, destroying out-of-sample generalization. To prevent this:

- **Immutable Data Boundaries**: The evaluation dataset is physically segregated on the file system. The candidate generation code operates with restricted read-only permissions and has no structural visibility of the hold-out dataset path.
- **Hold-out Signatures**: Every validation and hold-out data block is paired with a SHA-256 hash stored in the permanent provenance ledger. If any candidate execution alters the data block, the hash verification fails, the candidate is discarded, and a security alert is published.
- **Dataset Splitting**:
  - **TRAIN (60%)**: Used by the ACPE to discover and adapt policy weights.
  - **VALIDATION (20%)**: Used during the optimization loops to refine parameters.
  - **HOLDOUT (20%)**: Kept completely isolated. Checked only once by the Falsification Gate during the final promotion step.
  - **ADVERSARIAL**: Special, high-volatility, low-liquidity synthetic regimes injected to check boundary safety.

## 4. Uncertainty Measurement vs. Pass/Fail Grading

AlphaAlgo rejects naive binary grading. All performance metrics are reported with calculated **Confidence Intervals (CI)** and **Expected Calibration Error (ECE)**.

### A. Expected Calibration Error (ECE)
ECE measures how well the agent's predicted decision confidence maps to empirical accuracy. The decision confidence space $[0, 1]$ is partitioned into $B$ equal-width bins. Let $I_b$ be the interval of bin $b$. The ECE is:

$$\text{ECE} = \sum_{b=1}^{B} \frac{|B_b|}{N} \left| \text{accuracy}(B_b) - \text{confidence}(B_b) \right|$$

Where:
- $\text{confidence}(B_b)$ is the average confidence of decisions in bin $b$.
- $\text{accuracy}(B_b)$ is the true positive rate of decisions in bin $b$.

A candidate with high returns but poor calibration ($\text{ECE} > 0.15$) is flagged as **Overconfident/Hallucinated** and rejected.
