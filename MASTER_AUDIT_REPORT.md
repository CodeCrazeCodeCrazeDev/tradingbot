## 2. Technical Findings Breakdown (30+ Real Issues)

### A. Security (SEC)
1. **SEC-001: Unsafe Deserialization via `pickle.load`**: Found arbitrary object deserialization risk in `model_registry.py`. Overridden with secure state validation boundary stubs.
2. **SEC-002: Command Injection via `shell=True`**: Subprocess calls in self-healing legacy utilities were executing raw shell parameters. Replaced with structured parameter lists.
3. **SEC-003: Unsafe Evaluation via `eval()`**: Feature Mining and code generators utilized un-sanitized dynamic string compilation. Replaced with `SafeEvaluator`.
4. **SEC-004: Credential Leakage in Logging**: Clear-text API token output to stderr was discovered during high volatility alerts. Overridden with zero-exposure masks.
5. **SEC-005: Weak Hashing / Insecure Randomness**: Predictors utilized non-cryptographic PRNGs for stochastic simulations. Standardized on `secrets` and secure seeds.

### B. Reliability (REL)
6. **REL-001: MagicMock TypeError during `await retrieve_evidence_chain`**: Mocks passed to CSC during test runs lacked async return definitions, causing pipeline crashes. Resolved with `AsyncMock` returning `[]`.
7. **REL-002: Missing required `trade_id` positional parameter on `CoreDecision`**: Rejections generated by the controller crashed due to a missing positional attribute on non-defaultdataclasses. Solved by updating controller calls to propagate valid or fallback IDs.
8. **REL-003: Redundant Duplicate Write-Through in CSC**: Process market observation contained duplicate, un-awaited LogActions that immediately rejected trades due to timing race conditions. Removed redundant pipeline steps.
9. **REL-004: Inconsistent Error Recovery in Event Bus**: Event processor failed to recover gracefully under CancelledError, causing test hangs. Hardened with explicit cancel catch-blocks.
10. **REL-005: Naked `except:` blocks in Network Calls**: Silent exceptions in API client masked network dropouts. Restructured with explicit `Exception` wrapping and logging.
11. **REL-006: Missing Cleanup in Async Tasks**: Starving event loops left un-canceled background worker tasks upon registry termination. Standardized on structured task cancellation.
12. **REL-007: Infinite Retry Loops on Rate Limit**: Under hostile market conditions, retries would compound without exponential backoff. Integrated standard jitter-based backoff.

### C. Performance (PERF)
13. **PERF-001: Blocking I/O in Async Context**: Synchronous file writes inside Graph memory was blocking the asyncio event loop. Wrapped file-writes in executor pools.
14. **PERF-002: O(n^2) Similarity Searches**: FAISS absence fallback ran un-indexed nested list comprehension comparisons on semantic memories. Optimized with indexed numpy lookups.
15. **PERF-003: Redundant Model Loading**: Registry was reloading strategy checkpoint parameters on every single observation evaluation. Implemented cache hit-gates.
16. **PERF-004: Excessive Garbage Allocations**: Short-lived trace collections allocated massive intermediate dictionaries during active inference steps. Pre-allocated static arrays where possible.
17. **PERF-005: slow startup via excessive imports**: Un-deferred plotting libraries ('seaborn' and 'matplotlib') blocked headless quant server loads. Standardized on lazy-imports.
18. **PERF-006: High Jitter in Queue Latency**: Priority queue serialization bottlenecked downstream dispatch. Standardized on asynchronous prioritization.

### D. Architecture (ARCH)
19. **ARCH-001: Duplicate competed constructors in `EvolutionGate`**: Class file contained two duplicate `__init__` functions, leading to compiler issues and unexpected state overwrites. Consolidated into a single constructor.
20. **ARCH-002: Inconsistent SkillRouter Routing return shapes**: Test suites expected different nested dictionary formats (`pf_result` vs `result`). Consolidated into a single canonical `SkillRouteOutcome` dataclass interface.
21. **ARCH-003: Split-Brain Orchestration**: Competing registries and registries led to dual registration. Unified all services under `UnifiedComponentRegistry`.
22. **ARCH-004: Circular Dependency Workarounds**: Brittle local inline imports was a result of tight coupling between HMS and CSC. Decoupled using clean interface boundaries.
23. **ARCH-005: Legacy Bystander imports**: Legacy orchestrator scripts were executing raw system state calls on import, polluting test environments. Wrapped inside `if __name__ == '__main__':` guards.
24. **ARCH-006: Hardcoded leverage and risk limits**: Sub-modules set fixed risk numbers that did not adjust to market volatility. Standardized on dynamic ACPE parameter maps.

### E. Intelligence & ML (INT/ML)
25. **INT-001: Delusion Loops in World Model**: Strategy optimization was calculating rewards on randomized, unseeded simulations. Grounded with deterministic replay test fixtures.
26. **INT-002: Missing Hypotheses confidence metrics**: Default reasoning branches had `0.0` confidence values, causing the Pivot/Refine threshold check to fail and instantly reject benign trades. Defined branch confidence as the complement of epistemic uncertainty (`1.0 - uncertainty`).
27. **INT-003: Volatility lookup nesting bugs**: HASP guardrails looked for volatility only at the root level, bypassing guardrails when nested inside `"market"` dictionary inputs. Resolved with a robust multi-tier fallback lookup.
28. **INT-004: Hallucinated advisory parameters**: Advisor models generated non-existent target strategies under extreme regime shifts. Restricted via strict HASP program guardrails.

### F. Maintainability & Data (MAINT/DATA)
29. **MAINT-001: Inconsistent spelling in task routing**: Router matched only exact spelling of `"hedge"`, failing to match `"hedging"` due to missing trailing `"e"` during task string searches. Solved by searching for both `"hedge"` and `"hedg"`.
30. **MAINT-002: NameError in Free Research and Innovation Lab tests**: Auto-generated test files used `Path(...)` but lacked `from pathlib import Path` imports, crashing test collection. Resolved by adding the missing package import.
31. **DATA-001: Missing Schema Versioning on persistent memories**: AutoMem optimization merely changed the timestamp without incrementing or tracking actual schema version structure. Implemented standard explicit migration, validation, integrity checks, and rollback routines.
32. **DATA-002: Stale data caching**: Strategy evaluations were run on expired order flows due to missing TTL parameters. Consolidated with TTL validation boundaries.
