## 2. Non-Bypassable AST Gating & Scans

Any python script or code patch generated by an agent (e.g. `CodeEvolutionEngine`, `SelfModifier`) must undergo a non-bypassable AST-level syntax scan before execution:

*   **Forbidden Keywords**: `eval`, `exec`, `pickle`, `subprocess`, `os.system`, `shutil`, `sys`.
*   **Allowed Libraries**: Standard mathematical and data frameworks (`numpy`, `pandas`, `scipy`, `sklearn`, `torch`, `statsmodels`).

### **AST Gating implementation**:
```python
import ast

def verify_code_safety(code_string: str) -> bool:
    forbidden_calls = {"eval", "exec", "compile", "__import__"}
    forbidden_modules = {"os", "sys", "subprocess", "shutil", "socket"}

    try:
        tree = ast.parse(code_string)
    except SyntaxError:
        return False

    for node in ast.walk(tree):
        # Check call names
        if isinstance(node, ast.Call) and isinstance(node.func, ast.Name):
            if node.func.id in forbidden_calls:
                return False
        # Check imports
        if isinstance(node, ast.Import):
            for alias in node.names:
                if alias.name in forbidden_modules:
                    return False
        if isinstance(node, ast.ImportFrom):
            if node.module in forbidden_modules:
                return False

    return True
```

## 3. Sandboxed Container Boundaries

If the AST scan passes, the code is executed in the `StrategySandbox` within a separate, isolated OS subprocess:
*   **Resource Throttling**: The process has a hard CPU limit of 10% and memory cap of 1GB.
*   **Time-out Limits**: A strict 15.0s wall-clock SIGTERM process-level timeout prevents thread-leaking or hanging.
*   **Filesystem Isolation**: The sandbox cannot write to or modify files in `trading_bot/` or the active project root directory, keeping the primary repository completely clean.
