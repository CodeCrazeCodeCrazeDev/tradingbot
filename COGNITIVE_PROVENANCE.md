## 2. Cryptographic Provenance Chains

Every trade proposed to the event bus carries an `InstitutionalProvenance` metadata block:

```python
@dataclass(frozen=True)
class InstitutionalProvenance:
    pipeline_version: str
    git_sha: str
    reproducible_seed: int
    data_version_hash: str
    schema_version: str
    signature: str
```

The `signature` is generated by hashing the serialized `LogAction` payload, the `CognitiveConfiguration` checksum, and the physical risk limits state using an HMAC-SHA256 signature signed by the `ImmutableShield`.

## 3. Deterministic Replay Validation

The Deterministic Replay Framework (`ReplayManager`) enforces perfect reproducibility by aligning standard random generators:
1.  **State Alignment**: The `ReplayManager` instantiates the exact parent `CognitiveConfiguration` and imports the matching git SHA.
2.  **Seed Alignment**: Restores standard library `random`, NumPy (`np.random.seed`), and PyTorch (`torch.manual_seed`) random states using the `reproducible_seed` saved in the provenance metadata.
3.  **Data Playback**: Feeds the exact historical bar/tick sequence recorded in `market_data.db`.
4.  **Assertion**: The replayed decision vector must be identical to the captured live trade proposal. If any variance is detected, a state regression is flagged, and the parent model is locked from further updates.
