# Phase 1: Institutional Hypothesis Discovery & Inventory Matrix (2026)

## 1. Scope & Taxonomy of Hypotheses

Across AlphaAlgo, hypotheses exist under multiple domain-specific terminologies depending on the abstraction layer. To achieve complete scientific coherence, **every prediction, state estimate, proposed trade, parameter mutation, rule extraction, and scenario rollout is treated as a falsifiable scientific hypothesis**.

### Hypothesis Terminology Alias Map
- **Prediction / Forecast**: Temporal expectation of price movement, volatility, or volume in `UnifiedWorldModel` or ML forecasting heads.
- **Belief / Regime Belief**: Latent state representation in `MarketRegimeAdapter` or Bayesian filters.
- **Assumption / Premise**: Pre-conditions for trading strategy execution, checked in `ImmutableShield` and `VerifierSwarm`.
- **Thesis / Strategy Candidate / Alpha**: Symbolic math expression or logic genome in `GeneticAlphaSearch` and `EvolutionaryEngine`.
- **Signal / Trade Idea**: Immediate tactical trade proposal generated by `PHCEDAI` or `CSC`.
- **World Model State / Scenario**: Tri-horizon simulated future (Nominal, Stressed, Extreme) in `ImaginationEngine`.
- **Causal Model / Explanation**: Structural causal DAG hypothesis induced by `CausalWorldModelInduction`.
- **Optimization Proposal / Experiment**: Code or hyperparameter mutation in `RecursiveSelfImprovement`.

## 3. Explicit Lifecycle Points Catalog

### 3.1 Hypothesis Creation Points
1. **SRE Core**: `ScientificReasoningEngine.observe()` (`trading_bot/core_agent_system/scientific_reasoning/core.py`)
2. **Curiosity Engine**: `HypothesisGenerator.generate_from_anomaly()` (`trading_bot/foundation_agents/curiosity_engine/hypothesis_generator.py`)
3. **Research Extraction**: `HypothesisExtractionEngine.extract_from_research()` (`trading_bot/alpha_research/hypothesis_extraction.py`)
4. **CSC Branching**: `HypothesisGenerator.generate_competing_branches()` (`trading_bot/core/csc/hypothesis.py`)
5. **Alpha Expression Search**: `GeneticAlphaSearch._generate_random_expression()` (`trading_bot/apex_fi/alpha_mining.py`)
6. **Scenario Rollout**: `ImaginationEngine.simulate_scenarios()` (`trading_bot/world_model/imagination.py`)
7. **Empirical Rule Induction**: `AbsoluteLaws._create_draft_strategy()` (`trading_bot/market_teacher/absolute_laws.py`)
8. **PHCE-D Tactical Hypothesis**: `PHCEDAI._generate_hypothesis()` (`trading_bot/core/phce_d_engine.py`)

### 3.2 Hypothesis Evaluation Points
1. **Bayesian Posterior Calculation**: `ScientificReasoningEngine.bayesian_update()` (`trading_bot/core_agent_system/scientific_reasoning/core.py`)
2. **Adversarial Critique**: `EpistemologyEngine.analyze_hypothesis()` (`trading_bot/core_agent_system/cds/epistemology_engine.py`)
3. **Evidence Synthesis**: `ParallelHypothesisCorrectionEngine.process()` (`trading_bot/core/phce_d_engine.py`)
4. **Graph Constraint Verification**: `CSC._verify_evidence_hard_constraint()` (`trading_bot/core/csc/controller.py`)
5. **Robustness & Overfitting Diagnostics**: `StrategyDiagnostics` (`trading_bot/alpha_research/strategy_diagnostics.py`)
6. **Alpha Decay Clock**: `AlphaDeathClockManager` (`trading_bot/alpha_research/alpha_death_clock.py`)

### 3.3 Hypothesis Rejection Points
1. **Low Posterior demotion**: SRE Step 12 sets state to `REJECTED` if $P(H|E) < 0.20$.
2. **Red-Team Veto**: Verification Swarm or `ImmutableShield` detects hard risk violation.
3. **Factor Entropy Decay**: `LivingFactorLibrary._retire_factor()` in `alpha_mining.py`.
4. **Causal Falsification**: `ImaginationEngine` detects failed counterfactual under $do(X)$.

### 3.4 Hypothesis Promotion Points
1. **Institutionalization**: SRE Step 14 promotes hypothesis when $P(H|E) \ge 0.85$ and $ECE \le 0.15$.
2. **Production Factor Promotion**: `LivingFactorLibrary._promote_factor()` in `alpha_mining.py`.
3. **SAGE Memory Consolidation**: Working memory hypothesis pushed to Long-Term Graph Memory in `trading_bot/core/hms/memory.py`.
