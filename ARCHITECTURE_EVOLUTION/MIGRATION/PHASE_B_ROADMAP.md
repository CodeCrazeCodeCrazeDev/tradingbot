# Phase B: Implementation Roadmap

## 1. Foundation Hardening 
- Finalize `IntegratedAgentSystem` (CSC) as the mandatory entry point.
- Implement `UnifiedRiskEngine` as proposed in ADR 006.
- Enforce `ImmutableShield` on all trade outputs.

## 2. Intelligence Consolidation 
- Port `intelligence_core` agents to the `UnifiedComponentRegistry`.
- Migrate `structural_memory` to HMS.
- Unified self-improvement loop using `EvolutionGate`.

## 3. Tier 1 Integration 
- Connect `market_intelligence` and `signals` to World Model V3.
- Active Inference driven execution layer.

## 4. Verification Swarm 
- Deploy `VerificationSwarm` to audit all Tier 1 decisions.
- Chaos testing and Institutional stress-testing.

## 5. Clean-up (Ongoing)
- Archive redundant modules after verification of migration.
- Final documentation and Institutional readiness certification.
