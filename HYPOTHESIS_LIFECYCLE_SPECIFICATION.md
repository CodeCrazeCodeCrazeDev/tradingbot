# HYPOTHESIS_LIFECYCLE_SPECIFICATION.md
## Scientific Hypothesis Lifecycle Specification

This specification governs the lifetime and state transitions of hypotheses (alphas, strategies, beliefs) generated by AlphaAlgo.

---

## 1. Non-Lossy State Transition Lifecycle

All hypotheses must map onto one of the following canonical terminal or active states, and under no circumstances is any scientific history allowed to be silently deleted.

```
 [Created] ──→ [Observed] ──→ [Under Evaluation]
                                     │
                 ┌───────────────────┼───────────────────┐
                 ▼                   ▼                   ▼
            [Confirmed]         [Rejected]         [Inconclusive]
                 │                   │                   │
                 ▼                   ▼                   ▼
        [Institutionalized]      [Dormant]          [Deprecated]
```

### State Definitions
*   **Created**: Initial instantiation, metadata and prior belief serialized.
*   **Confirmed**: Hypothesis passes out-of-sample backtesting metrics ($DSR > 2.0$).
*   **Rejected**: Hypothesis fails significance or is falsified by counterevidence.
*   **Inconclusive**: Insufficient statistical power to reject or confirm.
*   **Dormant**: Hypothesis is stored in the HMS Ledger but is currently inactive.
*   **Institutionalized**: Hypothesis is promoted to Layer 6 production execution rules.
*   **Deprecated / Superseded**: Replaced by a more generalized or higher performing successor hypothesis.
