# ADR-003: Causal vs Correlative Alpha Validation Engine
======================================================

## Status
Approved

## Context
Many alpha discovery platforms select features based purely on correlation with price returns. However, in financial markets, correlation does not imply causation, and correlative edges decay rapidly when the underlying regime shifts.

## Decision
We implement Granger Causality and Structural Break tests inside the `CausalityAndStructuralBreakTester` class in `trading_bot/research/research_os.py`. Features must demonstrate statistically significant causal predictive power before being promoted as approved alphas.

## Consequences
- Protects the system against temporary spurious correlations.
- Improves alpha durability across regime transitions.
- Minimizes capital drawdowns by proactively identifying structural market breaks (using Chow Test proxies).
