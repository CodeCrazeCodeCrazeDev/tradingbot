# ADR-006: False Discovery Rate (FDR) Control
============================================

## Status
Approved

## Context
When running large-scale automated search loops across thousands of possible trading ideas, many random hypotheses will appear to have a statistically significant p-value (< 0.05) by pure chance. Deflated Sharpe ratio controls help, but we also need a standard control to bound the expected proportion of false positives among all accepted discoveries.

## Decision
We implement Benjamini-Hochberg False Discovery Rate (FDR) control inside `ResearchConstitution.assert_fdr_control` in `trading_bot/research/constitution.py`. The gate requires that any batch of proposed hypotheses must be collectively evaluated using BH-adjusted significance criteria.

## Consequences
- Guarantees that the expected proportion of false discoveries is strictly bounded by the alpha target (default 5%).
- Prevents spurious signal promotion in high-dimensional search environments.
- Standardizes testing rigor across large portfolios of concurrent research ideas.
